# 数据库使用方法

公开版附有完整的公共转写规则及其中的例句，例句和辨析案例可自行导入。已有授权的资料时，可请智能体按下文整理规则、例句或案例，再运行查询程序。

开始新歌时，先完整阅读选定的手语歌讲义与小班材料，再用这里的规则、例句和辨析案例查找具体问题。数据库帮助定位和比较，不能代替对完整讲义及图示的理解。

双击[规则与例句查询程序](../规则与例句查询程序.pyw)，搜索关键词或筛选转写规则、来源。点击资料名称，用系统默认应用打开原件。

## 查例句、规则与修改理由

| 你想了解什么 | 怎样查 |
|---|---|
| 某句话可以怎么打 | 搜相近原句，看转写、上下文和原件 |
| 一条规则有哪些实例 | 选择转写规则，或点击结果中的规则编号 |
| 为什么这样修改 | 查看辨析案例的“何时参考”“核心辨析”，再展开完整讨论 |
| 想直接看表格 | 打开转写例句表或转写辨析案例表 |
| 想读规则全文 | 打开[公共转写规则](公共转写规则.md) |

也可以直接告诉智能体：

> 找几个把长句拆成短句的例子，给我看原句、转写和出处。

教材简答要连同前面的提问读，完整对话在转写例句表的“会话上下文”页。涉及动作方向、表情、斜体、删除线或图示时，回看原件。同一句可以有不同的合理打法，案例也可能说明规则的边界。

## 审核新的转写规则

审核时用待审编号指明条目；待审编号与已收录规则的编号互不对应。编号保持稳定，便于查找和讨论。

打开[转写规则提炼待审](转写规则提炼待审.md)，主要判断建议文字是否准确、适用范围是否合适、例句是否支持概括。你可以一次审核多条，直接说：

- “通过这些编号，按建议位置补充。”
- “这条只用于这首歌。”
- “这条改成……，改完再给我看。”
- “这条改成……并通过。”
- “这条不采用。”或“这条先保留，等试打后再看。”

说决定时带上实际待审编号；只认可某个打法时，可以说“只采用本例打法，不作为公共规则”。“改完再看”表示继续待审，“通过”表示采用该条写明的文字和去向。

审核完成后，在公共转写规则或对应歌曲的本曲转写规则中查看结果，相关案例保留审核记录。没有待审条目时，待审文件的条目区留空；“下一个新增编号”只是预留号码，不表示已有对应条目。

想修改或撤回已通过的内容，指出收录后的规则编号即可。程序数据无需老师维护；修改案例文字后，让智能体更新查询和目录。
