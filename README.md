### 🌟 理想目标

**自动生成稿件不是终点，帮助手语老师在备课中学习手语才是。** 希望每一次讨论、比较和修改，都能让老师多理解一点手语表达。

希望有基本配置的手语老师能顺利走完选歌、制作、定稿和反馈的过程，成稿的上限更多取决于老师的手语水平，而不是计算机操作或提示词撰写能力。制作质量应有较高的保底水平，未来希望不同智能体和电脑都能做出符合规范的讲义。

**随着更多老师参与，希望个人经验也可以经过审核，便捷地汇入共同经验，供以后复用。这是我最想实现的功能，尤其需要大家帮忙！** 提供者可以选择分享一条经验、一个片段或一份讲义，并决定使用范围。现有讲义和学习材料也需要逐项确认授权，扩大使用范围前征得制作者同意。

工具和资料更新时，怎样保留每个人自己的讲义和修改，仍需要一起研究。这些目标可能需要重新考虑项目架构，我一个人的能力做不到，期待有人接力，把工坊继续往前推。

## 下载

公开工具版采用 v3.2.0。Windows、macOS、Linux 共用一个工作空间。v3.2.0 公开版 ZIP 将在《26春手语小班知识纯享版》整理完成后发布。想查看或修改最新源码，可用 **Code → Download ZIP**。解压后按下文配置。源码试用期间如未附纯享版，先用内置公共转写规则和获准自带的资料，向老师说明参照缺口。

## 配置智能体

本项目使用 Codex 建立，尚未在 DSH、WorkBuddy 中试用。选择支持本机系统的智能体客户端，将解压后的整个“手语歌智能工坊”文件夹设为工作目录，并要求智能体先完整读取 `AGENTS.md`，再按当前任务读取其中链接的要求。客户端需要支持本地文件读写、运行 Python、查看图片和网络检索；不同客户端和系统的完整备课能力还有待验证。

客户端账号和模型按客户端要求配置。工坊不内置大模型或独立聊天界面；客户端可能调用远程模型服务，请按材料允许的使用范围设置权限。首次接管可以说：

> 请完整阅读 AGENTS.md，自动准备环境和国家通用手语词典，再告诉我是否可以开始备课。其他词典先列出目录，等我选择。不修改讲义。

Python、依赖和词典下载由智能体处理；确实需要你操作时，它会说明具体步骤。其他词典可以在[可下载词典](dictionaries/可下载词典.md)中查看，告诉智能体下载你需要的。国家通用词典优先使用，其他词典可结合出处和表达目标参考。

配置完成后，按[使用说明](使用说明.md)开始备课；正在制作的歌曲放在[工作台](工作台/使用说明.md)。

## 个人内容与更新

工作台里的歌曲、截图和制作记录属于使用者的个人内容，不会因为使用工坊而公开。个人格式偏好可以请智能体记录，自己的经验和材料也可单独保存。你改过的资料也请妥善保存。

旧版覆盖包只适用于发布说明指定的版本。涉及资料或目录结构的更新，请按该版本说明备份并比较，保留个人文件和本机词典。
