# 讲义制作与复核

开始试排、制作或检查讲义前完整阅读本文件，并读取本曲格式要求与选定参照的完整页面。路径与命令均以项目根目录为起点。总流程见[AGENTS.md](../../AGENTS.md)。

## Word图解与打印

通用目标是黑白可读、歌词和转写区分清楚、图词对应、尽量少翻页。制作前读取本曲“本次讲义格式要求”，按已选参照的完整页面确定字体字号、转写标记、图片高度与重复段是否省图。

### 开头与记号说明

新讲义开头统一使用front_matter：第一行居中只写歌名，不加歌手；第二行将实际授课日期及手语老师署名整行右对齐，格式为 `--YYYY.MM.DD by授课老师署名`，日期和署名都取本次老师确认的信息。日期是授课日期，不用生成日期、文件日期或往届日期代替；缺少日期或姓名时集中确认，已明确的信息直接沿用。其后用几句简短说明介绍当前讲义实际使用的记号系统：检查本稿的斜体、删除线、①②、重复符号、参考图框和短说明等，按本次含义列出，用不到的不列；不要从历史稿照搬整套说明或自行推断记号含义。老师调整记号时同步核对正文用法及开头说明。歌曲简介和其它开场注释不默认添加，老师另有安排时按其要求处理。

### 图示顺序与短说明

按选定原件的完整页面编排。普通图示行按转写词序排列；选择、并列、同时动作等确实不适合线性图链时，保留适合表达的整体图解或特殊排列，在sequence_exception中简短注明组织方式和原因，结合原稿判断，不为了通过程序强改打法。例外仍须保持图文对应，成品按指定排列核对，并列为人工复核项。普通图示行是一条动作链：图片和必要的无图短说明共用有序sequence，短说明独立放在所说明的动作位置，不能统一放到行末、附在任意图片后或另起图下说明段。文字说明从简，已有图片能说明的内容不重复写；有意不展示某个词位时用内部omit交代理由，不为每个词补一段文字。没有老师要求或明确参照依据时，不自行给每图重复加中文词标签、添加歌词行号、图片统计、“图序”、额外栏目或长篇开头提示，也不用长括号动作说明替代具体转写。程序的行号和图片统计留在内部检查中。交付前对照版式参照，并核对对象是否明确、词汇检索是否充分、空间关系是否落实、描写是否必要、未决内容是否清楚；技术检查通过不等于转写完成。

确认转写后再贴词典原图，普通图示使用嵌入型横排并保持比例；特殊整体图解按已确定的组织方式保留。裁空白或给横长图补白时，不能裁掉手形、方向箭头或动作部分。图片段落用足够的行距，不以小于图高的固定行距挤压。参考虚线框出现上边截断时，可按本曲版式明确启用reference_frame_padding留边；未指定的版式不自动改变，修正后再次看图框四边。

### 最后评估补白

补白作为贴图与排版完成后的最后一项版式调整。先找实际页面中拥挤或换行的图示行，从中选择适合瘦身的图片；另标出手形、面部等大小或线条粗细明显失衡的图片。空余充足且视觉协调的行通常不调整；图片比例仅辅助筛选，结合实际行宽及同排线图大小判断，模型逐张看图判断是否确有必要，不能仅凭横长就补白。集中向手语老师报告具体歌词位置、候选图、建议补白程度（或内容缩小比例）、理由及预期换行影响；老师确认后才开始补白，未确认的图片保持原状，避免逐图打断。调整时先检查过大的图间隔和能安全裁去的无用左右白边，再考虑补白；矩形裁剪按原图像素精确控制，不能裁掉有效动作。原件保留，只为获确认的图片在制作输入中设置content_scale，由同一制作入口生成带白边的派生图并嵌入新稿，不重复套用旧裁图；默认不要求老师另管图片副本。具体计算及记录见[制作输入与检查](../tools/讲义制作输入与检查.md#扁图补白)。不规则裁剪与交错放置作为特殊情况下的人工处理建议，明确当前入口未自动支持。完成后再次检查线图可读性、图示换行、分页及图框四边；过小则减少补白或合理换行，向老师反馈结果。

### 老师版与学生版

必要的讨论提示、解释或翻译思路写入teacher_note，只在老师版以【】包裹输出；按教学需要选写，不要求逐句生成。学生/打印版排除teacher_note，但保留动作链中学生确实需要的短说明。制作和检查均显式选择同一edition（默认student）；【】是正文字符，不会随Word“打印标记”开关消失。不要在lyrics、transcription或sequence中混入老师专属备注。重复歌词的转写同步复制，保留斜体、删除线、①②和重复标记；刻意不同的方案单独判断。

### 原稿保护与逐页检查

编辑以手语老师指定的最新稿为准；只读检查不授权改稿。修改前另存可恢复副本。老师的截图和裁图应保留。

打印检查要逐页看Word导出的PDF或页面图：图框四边、文字缺失、空格、同句断页、大空白、重复段、页码、字体和图片。结构检查发现候选问题，不能替代页面预览；二维码须实际扫码。已有讲义只检查本次范围，不自动统一全部字号或图高。

### 制作输入与核对

制作只使用scripts/make_handout.py一个入口。歌词、转写、已选图片、短注释、裁图范围与重复引用作为内容输入，和Word排版分开；新稿统一使用version: 2的制作JSON（接口见[制作输入与检查](../tools/讲义制作输入与检查.md)）；既有Word可只读检查或按授权另存局部编辑副本，不批量转换历史歌曲。每首歌只保留一份当前制作输入，临时转换后选定一份，不并行维护多份。

内部词条名、义项和来源用于选图追溯；action说明实际选用的动作部分；这些字段与图片替代文本均不自动打印成中文标签。sequence各项用at关联到transcription按“/”分隔后的词位，从1开始，默认按词序排列，明确的sequence_exception按指定组织方式排列；同一词位可有多图或短说明，不要求一个词只有一图。每个词位用image、text或有理由的omit交代，不能为满足核对而机械逐字配图。块级note及图片note不用于新稿，程序遇到会报错；短说明用独立text项，老师专属内容用teacher_note。record可选，仅保留确需追溯而不印入讲义的内容，不要求填写长解释。旧制作数据不自动改写，不增加迁移任务。

保留老师已有截图与裁图，不自动替换为词典整图；裁图范围须先看原图确认不截掉手形、箭头或动作，程序只能检查坐标和比例。配置项目的程序核对、页面复核和老师判断分工见[制作配置与检查责任对应表](../tools/讲义制作输入与检查.md#制作配置与检查责任对应表)；新增格式功能时同步扩展该表和检查测试。新稿交付前，用同一制作输入、版式及edition运行audit_docx.py，核对图文交错顺序、完整斜体和删除线、选图/裁图、重复与省图、参考框和标题层级，再逐页看导出页面。特别放大检查虚线框四边与短说明所在词位；检查器不能判断at所对应的动作是否语义恰当，也不能验证试打自然度。

试排与正式稿共用入口和格式原则；提前试排授权只改变获准提前的步骤，不免除其余要求。临时脚本只准备或转换数据、做一次性检查，不能另行实现Word排版。未变化的参照阅读、查词与老师已确认选择不重复；候选、查词命中和结构检查均不等于老师认可、语义判断或动作自然度验证。旧Word只按授权局部检查，不因新输入字段缺失被自动改写。
