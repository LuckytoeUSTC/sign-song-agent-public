# 转写与查词

开始新歌、讨论转写或核对选词前完整阅读本文件；已完成且未变化的工作直接接续。路径与命令均以项目根目录为起点。总流程见[AGENTS.md](../../AGENTS.md)。

## 制作前先明确讲义用途

开始制作前，请手语老师明确用途是手语课还是手语表演。已经明确过的用途直接沿用，不重复询问；兼有两种用途时请老师明确主次。将用途和本次重点记录在本项目的“本次讲义格式要求”中，作为后续讨论、制作和检查的基调，不编号为具体转写规则。

- 手语课：主要讲手语词、手语语法，并拓展文化知识；尽量使用自然手语，以学习和理解为主要目标。
- 手语表演：更注重动作的自然好看、节奏匹配歌词、画词对齐；对转写在自然手语表达上的自然性，以及专业性、准确性的要求相对较低，具体取舍按老师确定的表演目标进行。

选歌、转写讨论、讲解内容、选图与检查均按已确定用途展开。动作自然好看与自然手语的表达自然性是不同的考虑，不能混用；本次用途只在制作流程和本项目要求中记录，不放进公共转写规则。

按当前问题查阅资料：讨论表达时检索转写例子和修改案例并回看原件；制作或检查本曲讲义时先读工作台里的“本次讲义格式要求”。调用脚本、配置依赖、提取词典资源或处理Word技术问题前，阅读`scripts/TOOLING.md`对应部分。它提供命令和技术注意事项，不承担翻译流程。给手语老师的备课入口是`使用说明.md`，下载与配置见`README.md`。

## 从歌词到转写

选歌时一起考虑学生基础、速度、重复段、视觉表达和希望教的知识点。确认演唱版本和完整歌词，结合实际音频及歌词结构分段。可采用“主歌一、主歌二、副歌前段、副歌、桥段、尾声”等标题。结构不明确时先用中性的“第一段”等名称并说明待核对，不按固定句数硬分主歌副歌。歌曲总标题与段落小标题分层；同名副歌可以重复出现，但标题相同不代表转写相同或应自动省图。

### 先完整阅读参照材料，再检索数据库

开始新歌前，向老师集中说明两种参照方式：老师指定类似歌曲的讲义，或由智能体按歌词结构、题材、画面关系和节奏选择3—5首不同歌曲的最终版完整手语歌讲义。老师已经指定方式或材料时直接沿用；智能体自主选择时简短说明选择理由。现有参照讲义的教学用途均为手语课，不以用途差异区分它们。如果已有资料目录，选择前查阅其中的“版本／用途”备注中的歌曲特点与选歌参考；这些简评帮助筛选，不能代替完整阅读。对当前新歌，先上网检索歌词版本、歌曲背景和可播放音频，优先使用歌手、发行方等原始来源；核对老师给定版本，结合实际音频判断节奏与句子密度，再说明与参照歌曲的共同点。查不到可靠背景或无法听音频时明确哪些信息未确认，不凭歌名猜测、不擅自替换老师提供的歌词。版式参照使用`资料/手语歌讲义`中老师制作的原件及工坊当前内置规范；该目录的原件可以正常参考。历史AI生成稿不作为新稿格式依据。老师明确要求把旧稿更新至最新规范时再处理旧稿，日常新稿不批量迁移历史数据。优先使用标为最终版本的原件；同一首歌的多个版本不重复计数；修改稿仅在需要理解修改理由时补充阅读。老师指定不足3份时尊重其选择，不为凑数添加。在提出样句前，完整阅读 `资料/小班讲义/` 中《26春手语小班知识纯享版》的正文与图示，像阅读原小班讲义一样，记录与当前歌曲有关的表达方法及适用条件。老师另有获准使用的小班材料时也完整阅读。本任务已完整读过且未变化的材料无需重复读。

阅读全文并查看原件页面及关键图示，理解词汇如何组织、空间和方向如何表达、专名如何处理、描写怎样与词汇配合、注释如何穿插图示行。PDF提取文本和数据库摘要不能代替完整页面；图片不清楚时继续查看原页。明确一份版式参照，记录原件路径和采用的具体惯例；不把本曲选择推广为公共规则。专名可参考现有首字母指拼实例，提出具体候选，不仅留下“指拼或书写”的空泛占位。

在本曲备课依据中简短记录实际读过的材料及其对本曲表达、版式的启发，不要求老师另填检查表。建立完整材料印象后，再用已建立的公共转写规则、转写例句和辨析案例围绕具体问题检索，寻找支持例、不同用法与边界，并回看来源。小班规律是入门参考，不机械套用一种排列，不重新从头蒸馏小班讲义。

### 先审核少量文字转写，再完成全曲

先选2—4句代表性歌词，同时列出预计影响全曲的关键词，尤其专有名词、地名、文化词及特殊动作。先查资料并给出具体打法建议、依据和备用方案，再集中请老师补充熟悉的现成打法及偏好；不要让老师从零代替检索，也不要只审核样句表面文字而遗漏这些关键取舍。结合样句集中确认表达方向。老师明确认可样句后，生成全曲AI文字转写版，再由老师学习与比较表达、讨论并确认全曲文字转写、明确制作要求；全曲文字转写确认后才贴图制作。“继续”“做完稿”等笼统要求不自行解释为跳过全曲文字审核；只有老师明确批准跳过该环节、或已有已确认的全曲文字稿时才接续制作，不重复审核已批准内容。未审核样句前不生成整首贴图讲义。样句有问题时先调整，不反复逐句问同一决定。已有老师确认的转写直接沿用，不要求重新审核。全曲需要的新取舍集中汇报，老师不必逐项检查检索记录。

样句和全曲AI文字初稿使用“原句（实际转写）”呈现动作表达；给老师看的选词依据、候选差异、画面理解和待确认问题另起独立行，用【】包裹。文字讨论阶段可较充分说明可核对的依据和取舍，帮助老师比较；不能把解释、推测或“待老师确认”等讨论内容写进转写（）里。输出Word时使用teacher_note与teacher版，无图示链也适用；聊天或Markdown初稿同样遵循独立行【说明】。定稿图解阶段再按需要精简备注，不把“终稿少说明”误用成“文字初稿不给依据”。

逐句先理解画面：背景在哪里，谁做什么，对谁、朝哪里，出现什么结果。拆出对象、动作和位置关系，再查词、处理指代、否定范围、问题对象、停顿和表情，组织具体词汇、空间与必要描写。不能先写大段中文动作占位，再只找几张能配上的图。

文化名词或抽象句分清原义、来源支持的解释和联想；疑难给候选及原因，不捏造标准打法。作者未说明理由的例子，只写观察或署名智能体分析。动态动作的自然程度需要熟练老师判断。

围绕新老师的疑问讨论词汇、方向、空间、非手控、描写和节奏，而不是只给成品。教学可先让学生理解画面，再示范关键关系、慢速分句练习，最后合歌；按老师的目标与时间取舍。

## 查词和选图

先查`dictionaries/国家通用手语词典`，读完整动作说明。没有好的对应才查专业、历史或地区词典。现有词典没有合适表达时，讨论多种造词方式，由老师选择和试打；已有词的意义或文化联想不合适时，也保留老师自定义的自由。记录选用来源和原因。MDX含词条，MDD含图片或视频；两者及CSS等配套资源放在一起。

别名要找到其指向的词条，①②须明确对应哪一动作。查看完整动态图时核对手形、位置、掌向、运动；核对实际选用的动作和图示。

整词未检得或词义不合适时，按以下顺序继续，不立即改为自定义描写：

1. 检查别名、指向词条、多义项与动作变体，区分“没有精确词条”“现有义项不适合”和“配套图缺失”。
2. 把短语拆成表达所需的对象、动作、程度和位置关系，分别查询。例如车上、车后继续查车或汽车及上、后；岸边查河、岸、边；天空很高查天空和高；住在眼里查住或居住、眼及里或内。不能只查“天”的一天义项就放弃天空。
3. 继续查询语义合适的近义词、常用说法和组成词；必要时用包含搜索发现候选，再读完整动作说明。脚本查词和解析别名，模型判断词义；不机械逐字拆分文化专名，不因同形词或近义词出现就直接采用。
4. 用已找到的具体词汇建立对象，再组织方向、空间定位和动作关系。位置关系可用适当词汇或空间表达，按语境和试打选择，不要求每个汉字都有词图，也不把中文位置说明当成已完成动作。
5. 已有词汇不能充分表达形状、运动或关系时，再比较描写、类标记、借词与造词等方案。R09不赋予描写优先权；保留老师自定义的自由，给出具体候选和依据，由老师判断。仍待解决的动作明确标为待定，不能用“需老师示范”代替应完成的检索。

每个不重复的歌词句在本曲“查词与选图记录”中保留可核对的原句、当前转写及实际选用的词条、义项/动作与来源；机器查询结果保留实际命中和未命中。对有分歧的选词、空间或描写，简短记录取舍依据及未决问题，按需要展开，不为每句制造长解释。重复段引用首次记录，修改时同步更新。机器查询结果可保存为JSON供脚本复用，老师可读的记录用简明Markdown整理；不得把机器检索结果冒称语义判断，也不要求老师审核每句记录。

内置`dictionaries/指拼`提供用户原图裁切的32个指拼条目，无需下载。专名没有合适词条时，结合完整参照讲义提出首字母指拼等具体候选，老师选定后按顺序查询并贴原图。首字母逐字序列用空格分隔，如`S H`；`SH`作为单个查询词表示原图的SH手形，不混淆。指拼适用范围与命名方式仍由老师结合语境决定，不把拼写候选当作已批准转写规则。

只贴实际需要的动作图，分辨完整示意、运动路线和手形辅助图。老师手动截图或裁图保留。需要描写、变向或借图时写简短说明；缺图时先自动检查别名、配套资源和其它已获准使用的来源；仍无合适图时，提出可用的表达或示范方案供老师判断，确需老师现场示范或提供资料时再请其操作。每首歌的选图与词条记录放在自己的文件夹。

## 检索和学习

先根据问题查转写例句和修改案例的简短介绍。修改案例先匹配“何时参考”和“核心辨析”，找到相关问题再读对应歌曲“转写修改与辨析案例”内的完整正文及原件。前者记录转写例句，后者记录老师修改理由。

原句与转写只维护`资料/规则与例句数据库/转写例句.xlsx`，编号在第一列，原句紧随其后，保留原转写、必要上下文、来源位置、链接及稳定案例编号。教材会话在同一表的“会话上下文”页按轮次保存，检索可用`--context`展开；独立练习句不把相邻题目当语境。歌词区分版本和段落。原作者未解释时，不能冒充作者解释。

规则关联由逐例阅读后填写，关键词搜索只找候选。空白表示未关联，不表示没有适用规则。新规则及已有规则的增补统一输出到`资料/规则与例句数据库/转写规则提炼待审.md`，保留老师原话、出处、支持例和不同用法，未通过前不写入公共或本曲规则。老师明确决定通用、本歌曲、待议或不采用后再改变范围；对某句的认可不自动批准通用规则。本歌曲的打法和格式规则只放在`资料/讲义制作过程存档/<歌题>/本曲转写规则.md`及“本次讲义格式要求”中；公共转写规则可以引用案例，不复制本曲指令。模拟审核只是建议，不能改变老师裁定状态。

手语歌讲义同样提取转写例子并给出页码或正文段落。Word段落号包含空段，不等于打印页码。PDF文本可能丢失斜体和删除线；分析省略、动作变体或图词对应时必须看原页。

歌曲候选词条放在对应工作台；历史项目的查词记录留在该过程档案。

国家通用词典在接管时自动下载；其它词典按老师选择下载。历史案例引用的词典不一定已经安装，不把尚未下载误报为词条不存在。
